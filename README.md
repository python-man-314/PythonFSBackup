# PythonFSBackup
### A tool to back up your filesystem to another folder
The PythonFSBackup CLI helps to back up a file, folder, or your entire filesystem to another drive.  
*A restore tool is coming soon.* 
## How to use
Dependencies automatically install using `pip`, so you don't have to fight installation scripts. 
- First, the tool will ask to select a drive to back up to.
- You will then be prompted to enter the path of the file or folder you want to back up. To back up your entire filesystem, type X:/ (Windows, X is the drive letter. Python will switch to \ automatically) or / (Mac/Linux).
- The tool will zip the file automatically and copy it to your drive. (No formatting required.)
